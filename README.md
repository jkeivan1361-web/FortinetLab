
# Fortinet Ansible Labs (FortiGate + FortiWeb)

مجموعه‌ای آماده از ۱۶ آزمایشگاه (Lab) برای **اتوماسیون** و **تست امنیت شبکه** با Ansible روی FortiGate و FortiWeb.
هر لب یک پوشه مستقل است (`labs/NN-name/`) شامل `playbook.yml` و `README.md`؛ نیازی به نوشتن دستی کد هر صفحه نیست.

> ⚠️ **نکته صادقانه:** این پروژه روی دستگاه واقعی اجرا نشده است. ساختار، YAML و منطق پروژه با اسکریپت `check_repo.py` بررسی شده، اما نام ماژول‌ها/فیلدهای Fortinet و مسیرهای REST فورتی‌وب بین نسخه‌ها فرق می‌کند. اولین اجرا را روی لب تمیز بزنید و اگر خطا دیدید با `ansible-doc fortinet.fortios.<module>` و مستندات نسخه خودتان تطبیق دهید.
